# Cautio Fleet Incident Heatmap & Logbook

A dedicated geospatial safety mapping console visualizing verified vehicle telemetry incidents and equipment diagnostics from structured workbook snapshots.

## Key Capabilities

- Coordinate Precision Engine: Parses GPS coordinate coordinates directly from field inspection records with legacy format normalization.
- Corridors of Concern: Visualizes established high-risk logistics transport corridors across peninsular India with radial boundaries and severity metrics.
- Incident Inspection Logbook: Comprehensive searchable registry supporting sorting by timestamp, fleet identity, and resolution state.

## Setup

Open `index.html` in any modern web browser or host via static CDN providers.
